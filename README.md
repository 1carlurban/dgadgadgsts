# D Gadgets Website

A responsive, GitHub Pages-ready storefront for D Gadgets in Kampala, Uganda.

## Included
- Responsive premium storefront
- Product categories
- Search
- Product filtering
- Shopping cart using browser localStorage
- WhatsApp ordering
- Contact/location/opening hours
- No build tools or backend required

## Run locally
Open `index.html` in a browser.

## Upload to GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `styles.css`, `script.js`, and `README.md`.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select your main branch and `/ (root)`.
6. Save. GitHub will provide your live website URL.

## Customize
Edit the `products` array at the top of `script.js` to change product names, prices and categories.
